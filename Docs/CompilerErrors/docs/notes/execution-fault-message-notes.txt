В ExecutionFaultContract.cpp исправлены GetMessagePrefix и FormatMessage: категории отображаются в имена C# enum, используется wide-строка, для неименованного значения сохраняется числовой формат. Скрипт fix-execution-fault-message.ps1.
Проверка MSBuild /t:ClCompile Debug x64 для ExecutionFaultContract.cpp завершилась с кодом 1 (execution-fault-message-after.log). Первые ошибки теперь находятся в неконвертированных Stamp/TryGetCategory: std::runtime_error не имеет C# Exception.Data и InnerException, а передача по значению приводит к срезке исключений. Исправление префикса отдельно не подтверждено работающей сборкой или исполнением; требуется восстановить C++ контракт переноса категории и вложенной причины, не подменяя его заглушками.
