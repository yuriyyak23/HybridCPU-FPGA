В шести заголовках семь преобразованных вызовов Encoding.ASCII.GetBytes для фиксированных ASCII-префиксов с завершающим нулём заменены списками байтов std::vector. Буквы и нулевой байт сохранены. Скрипт действует только на литералы из букв и цифр, завершающиеся \0, и повторный запуск безопасен. При повторной компиляции CanonicalDecodedContracts.cpp ошибка Encoding в VirtualizationOperandSnapshot.h исчезла; остаются циклическая зависимость SafetyVerifier, неконвертированные Stream, ConditionalWeakTable и C# records. Проверка не охватывает полноценную сборку остальных затронутых файлов.
