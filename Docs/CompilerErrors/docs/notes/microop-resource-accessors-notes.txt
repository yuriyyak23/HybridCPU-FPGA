В MicroOp.h добавлены методы чтения и установки SafetyMask, ResourceMask и OriginalResourceMask, а также чтения ArchLegality и BackendHazard. Скрипт: restore-microop-resource-accessors.ps1. Методы установки двух последних масок пока не добавлены: у соответствующих типов поле Mask объявлено const, из-за чего стандартное присваивание удалено; требуется корректно восстановить семантику C# value type.
Проверка MSBuild /t:ClCompile Debug x64 для CanonicalDecodedContracts.cpp завершилась с кодом 1, журнал microop-resource-accessors-after.log. По-прежнему отсутствует закрывающая скобка MicroOp; компиляция методов не подтверждена. Для завершения класса необходимо восстановить интерфейс исполнения и зависимости Processor::CPU_Core, которая в YAKSys_Hybrid_CPU.Processor.h конвертирована многократными вложенными определениями.
