В MicroOp.h восстановлены методы TryGetPrimaryWriteBackResult, CapturePrimaryWriteBackResult и RefreshWriteMetadata с поведением базового класса из C#, а также абстрактный GetDescription; сигнатуры сопоставлены с производными C++ классами. Скрипт restore-microop-writeback-methods.ps1.
Проверка MSBuild /t:ClCompile Debug x64 для CanonicalDecodedContracts.cpp завершилась с кодом 1, журнал microop-writeback-methods-after.log: заголовок MicroOp.h остаётся незавершённым. Реализация и совместимость методов полной компиляцией пока не подтверждены. Для оставшегося интерфейса Execute, Commit и EmitWriteBackRetireRecords требуются корректные объявления Processor::CPU_Core и Span; Processor в текущем конвертированном файле содержит многочисленные повторные определения CPU_Core, ссылок на Processor::CPU_Core в исходниках более 3000.
