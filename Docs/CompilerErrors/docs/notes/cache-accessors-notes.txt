Cache accessors: restored constructor, capture, snapshot, occupancy, resident byte accounting, policy and clear operations from C# semantics. C# lock is reentrant, so ingressGate is a mutable recursive_mutex; this also permits const accessors to lock. Selected cache compile now reports its first errors in Request rather than accessors, but cannot establish behavior or link until the remaining file and codec are ported. restore-cache-accessors.ps1 is a one-time migration script, not a repeatable build step. CompactCodec.h now declares the intended C++ public interface, while CompactCodec.cpp is still untranslated and must be implemented with the original bounded Brotli wire format. The full-build log is current-full-build.log.
