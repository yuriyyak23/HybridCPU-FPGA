В InvalidVirtualThreadException.h подключён RegisterIdentity.h, в ResolveOrThrow значение VtId теперь используется как value type вместо shared_ptr согласно C#; скрипт fix-vt-resolver-value.ps1. В ExecutionFaultContract.h добавлены предварительные объявления InvalidOperationException и ArgumentOutOfRangeException, используемых только в shared_ptr; скрипт fix-execution-fault-forward-exceptions.ps1.
Сравнение vt-resolver-before.log и vt-resolver-forward-after.log показывает исчезновение ошибок неизвестных пространств имён и указанных типов. Проверка MSBuild /t:ClCompile Debug x64 InvalidVirtualThreadException.cpp по-прежнему не проходит: остаются ошибки конструктора исключения, форматирования и несовместимой реализации Stamp. Нельзя считать исправление проверенным в полной сборке; ExecutionFaultContract.cpp также содержит неконвертированный C# и требует отдельного восстановления.
